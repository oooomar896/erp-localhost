# برنامج نماذج الموارد البشرية — دار تول للاستشارات

نظام مكتبي محلي يعمل بدون إنترنت لإدارة وتخصيص وطباعة نماذج وخطابات الموارد البشرية، مطابق لوثيقة متطلبات المنتج ([DarTool_HR_PRD_Arabic.docx](docs/DarTool_HR_PRD_Arabic.docx)) والتصميم المرجعي ([ui ux.jpeg](docs/ui%20ux.jpeg)) وحقيبة النماذج ([5-namathej.pdf](docs/5-namathej.pdf)).

---

## 1. آلية حماية البرنامج وربطه بجهاز واحد فقط (Single-Device Lock)

تم بناء محرك التراخيص في [`src/license-engine.js`](src/license-engine.js) ليمنع مشاركة البرنامج أو تشغيله على أي جهاز آخر:

1. **قراءة البصمة الفيزيائية للجهاز (Hardware Fingerprint):**
   يقرأ البرنامج المعرّفات الفريدة لقطع الجهاز في نظام ويندوز (معرّف التشفير `MachineGuid` + معرّف اللوحة الأم `UUID` + الرقم التسلسلي للمعالج `ProcessorId`) ويولّد منها **معرّف جهاز فريد (`Device ID`)** بصيغة `DT-XXXX-XXXX-XXXX`.
2. **التفعيل لمرة واحدة برمز مشفّر خاص بالجهاز:**
   - عند فتح البرنامج على جهاز جديد، تظهر **شاشة التفعيل** وبها `معرّف الجهاز`.
   - يرسل العميل هذا المعرّف إليك (إدارة دار تول للاستشارات).
   - تفتح أداة توليد التراخيص الخاصة بك [`admin-keygen/keygen.html`](admin-keygen/keygen.html) وتدخل معرّف جهاز العميل لتحصل على **رمز التفعيل (`DTKEY-XXXX-XXXX-XXXX-XXXX`)** الموقع رقمياً بمعادلة `HMAC-SHA256`.
3. **منع النسخ أو المشاركة بين الأجهزة:**
   - يتم حفظ ملف الترخيص مشفراً بـ `AES-256-GCM` بمفتاح مشتق من البصمة الفيزيائية الحية للجهاز.
   - إذا قام العميل بنسخ مجلد البرنامج بالكامل أو أرسل رمز التفعيل لجهاز آخر، سيكتشف البرنامج اختلاف البصمة الفيزيائية للجهاز الجديد ويرفض التشغيل فوراً.

## 2. طريقة التشغيل

### أ. تشغيل البرنامج
- اضغط مرتين على ملف **[`تشغيل_البرنامج.bat`](تشغيل_البرنامج.bat)** (أو نفّذ الأمر `npm start`).
- سيفتح البرنامج في نافذة تطبيق مكتبي مستقلة على الرابط المحلي `http://127.0.0.1:4580`.

### ب. بيانات تفعيل جهازك الحالي (للتجربة الفورية)
- **معرّف جهازك الحالي (Device ID):** `DT-3393-E98E-C0E3`
- **رمز التفعيل الدائم لجهازك (Activation Key):** `DTKEY-0FD5-E056-37D1-1F44`

*(ملاحظة: قمنا بتفعيل جهازك الحالي مسبقاً لتتمكن من المعاينة المباشرة، ويمكنك تجربة شاشة القفل عبر حذف ملف الترخيص أو تشغيل أداة التراخيص).*

## 3. أداة توليد التراخيص (خاصة بمالك المشروع فقط)

توجد في مجلد [`admin-keygen/`](admin-keygen/):
1. **الواجهة الرسومية (بدون أوامر):** افتح الملف [`admin-keygen/keygen.html`](admin-keygen/keygen.html) في أي متصفح، الصق `Device ID` الخاص بالعميل، واضغط **توليد رمز التفعيل**.
2. **عبر سطر الأوامر:**
   ```bash
   node admin-keygen/cli-keygen.js DT-XXXX-XXXX-XXXX
   ```

> **مهم عند التسليم للعميل:** عند إرسال المشروع للعميل، احذف مجلد `admin-keygen` ومجلد `data` من النسخة المرسلة للعميل حتى يبقى مولّد التراخيص حصرياً لديك.
